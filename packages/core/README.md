# @quickservicets/core

The runtime of [QuickService.ts](https://github.com/ricardorauber/quickservicets), a backend framework for [Bun](https://bun.sh): write your entities as TypeScript types in `entities/`, and get CRUD routes, validation, filters, relations, file uploads, migrations and OpenAPI docs on an in-memory, SQLite, PostgreSQL or MongoDB database.

Create a project with the CLI, which adds this package for you:

```bash
bunx quickservicets init my-api --db sqlite
```

Documentation and source: https://github.com/ricardorauber/quickservicets
