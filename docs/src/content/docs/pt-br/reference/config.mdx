A configuração do projeto fica em `quickservice.config.ts` e é escrita com `defineConfig({ ... })`. Chaves aninhadas aparecem com pontos.

| Chave | Tipo | Padrão | Descrição |
| --- | --- | --- | --- |
| `database` | `DatabaseAdapter` | — | O adapter do banco: `memoryAdapter()`, `sqliteAdapter(...)`, `postgresAdapter(...)` ou `mongodbAdapter(...)`. |
| `server` | `object` | — | Configurações do servidor HTTP. |
| `server.port` | `number` | `PORT`, depois 3000 | Porta em que o servidor escuta (padrão `PORT`, depois 3000). |
| `server.publicUrl` | `string` | URLs relativas | URL base absoluta da API, usada nas URLs de arquivos (padrão: URLs relativas). |
| `production` | `boolean` | `NODE_ENV === "production"` | Modo produção: esconde detalhes internos de erros e desativa a documentação da API (padrão `NODE_ENV === "production"`). |
| `docs` | `object` | — | Configurações da documentação da API. |
| `docs.enabled` | `boolean` | ativada fora de `production` | Serve a documentação da API em `GET /docs` e `GET /openapi.json` (padrão: ativada fora de `production`). |
| `logger` | `Logger` | linhas JSON no stdout | Recebe uma entrada por requisição; o padrão é uma linha JSON por entrada no stdout. |
| `schema` | `string` | — | Schema padrão do banco para entidades sem um schema explícito; `DATABASE_SCHEMA` sobrescreve. |
| `storage` | `Record<string, StorageAdapter>` | um storage local em `uploads/` | Storages de arquivos com nome; entidades de arquivo usam `default`, a menos que `@storage` indique outro (padrão: um storage local em `uploads/`). |
| `files` | `object` | — | Configurações de upload e acesso a arquivos. |
| `files.maxSize` | `number \| string` | 10 MB | Maior upload, em bytes ou como `10MB` (padrão 10 MB). |
| `files.accept` | `string[]` | qualquer um | Padrões MIME aceitos (padrão: qualquer um). |
| `files.access` | `"direct" \| "proxy" \| "signed"` | direct quando o storage tem URL pública, senão proxy | Como funcionam as URLs dos arquivos (padrão: direct quando o storage tem URL pública, senão proxy). |
| `files.signedUrlTtl` | `number` | 900 | Validade das URLs assinadas, em segundos (padrão 900). |
| `files.signingSecret` | `string` | `FILES_SIGNING_SECRET` | Segredo HMAC das URLs de proxy assinadas (padrão `FILES_SIGNING_SECRET`). |
| `files.deleteOnRemove` | `boolean` | true | Apaga o objeto de um registro de arquivo quando o registro é apagado (padrão true). |
| `files.deleteReplaced` | `boolean` | true | Apaga conteúdos substituídos e arquivos que deixaram de ser referenciados quando uma referência muda (padrão true). |
| `files.deleteWithOwner` | `boolean` | true | Apaga os arquivos que um registro referencia quando o registro é apagado (padrão true). |
| `repositories` | `object` | — | Configurações dos repositórios. |
| `repositories.findAllMax` | `number` | 10000 | Máximo de registros que o `all()` de uma consulta fluente pode devolver (padrão 10000). |
| `populate` | `object` | — | Configurações de populate. |
| `populate.maxDepth` | `number` | 2 | Número máximo de segmentos num caminho de populate (padrão 2). |
| `migrations` | `object` | — | Configurações de migrations. |
| `migrations.autoInDev` | `boolean` | true | Se o `quickservice dev` cria migrations automaticamente para mudanças no modelo (padrão true). |
