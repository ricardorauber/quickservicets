Rode os comandos com `bun run quickservice <comando>` dentro de um projeto.

## `init`

Cria um projeto; dentro do monorepo do quickservice também liga os pacotes do workspace e os instala.

```bash
quickservice init [directory] [--db postgres|mongodb|sqlite|memory]
```

## `dev`

Faz o build e serve o projeto, refazendo o build e reiniciando quando entidades, endpoints, hooks ou a config mudam.

```bash
quickservice dev
```

## `build`

Gera o `.generated/`: models, rotas, tipos, o documento OpenAPI e a entrada do servidor.

```bash
quickservice build
```

## `migrate`

Aplica as migrations pendentes, ou migra para cima ou para baixo até a migration indicada.

```bash
quickservice migrate [target] [--force]
```

## `migration add`

Cria uma migration com as mudanças do modelo desde a última.

```bash
quickservice migration add <Name>
```

## `migration list`

Lista as migrations e se cada uma está aplicada.

```bash
quickservice migration list
```

## `migration remove`

Remove a última migration quando ela não está aplicada.

```bash
quickservice migration remove
```

## `migration script`

Imprime, ou grava num arquivo, o SQL das migrations entre dois pontos.

```bash
quickservice migration script [from] [to] [--output <file>]
```

## `--version`

Imprime a versão da CLI.

```bash
quickservice --version
```
