A rota de listagem gerada (`GET /<coleção>`) aceita todos os parâmetros abaixo; a rota de leitura (`GET /<coleção>/<id>`) aceita `fields`, `exclude` e `populate`. Parâmetros desconhecidos ou repetidos falham com 400.

| Parâmetro | Descrição |
| --- | --- |
| `limit` | Tamanho da página, 1–100 (padrão 20). |
| `offset` | Registros a pular, 0 ou mais (padrão 0). |
| `sort` | Campos separados por vírgula; prefixe com `-` para ordem decrescente (padrão `-createdAt`, depois `-id`). |
| `where[<field>][<op>]` | Filtros, combinados com AND; `in`, `nin`, `containsAny` e `containsAll` aceitam até 100 valores separados por vírgula. |
| `fields` | Caminhos separados por vírgula a devolver (listagem e leitura). |
| `exclude` | Caminhos separados por vírgula a deixar de fora (listagem e leitura). |
| `populate` | Caminhos de referência separados por vírgula a trocar pelos registros, até `populate.maxDepth` segmentos. |

## Operadores de filtro por tipo de campo

| Tipo | Operadores |
| --- | --- |
| `id` | `eq`, `ne`, `in`, `nin`, `exists`, `isNull` |
| `ref` | `eq`, `ne`, `in`, `nin`, `exists`, `isNull` |
| `boolean` | `eq`, `ne`, `in`, `nin`, `exists`, `isNull` |
| `enum` | `eq`, `ne`, `in`, `nin`, `exists`, `isNull` |
| `string` | `eq`, `ne`, `in`, `nin`, `exists`, `isNull`, `contains`, `startsWith` |
| `number` | `eq`, `ne`, `in`, `nin`, `exists`, `isNull`, `gt`, `gte`, `lt`, `lte` |
| `date` | `eq`, `ne`, `in`, `nin`, `exists`, `isNull`, `gt`, `gte`, `lt`, `lte` |
| `refArray` | `contains`, `containsAny`, `containsAll`, `size`, `isEmpty` |

## O que cada operador significa

- `eq`: igual a
- `ne`: diferente de
- `in`: é um destes
- `nin`: não é nenhum destes
- `gt`: maior que
- `gte`: maior ou igual a
- `lt`: menor que
- `lte`: menor ou igual a
- `contains`: contém (sem diferenciar maiúsculas; em reference arrays, contém o id)
- `startsWith`: começa com (sem diferenciar maiúsculas)
- `exists`: tem valor (`true`/`false`)
- `isNull`: é null (`true`/`false`)
- `containsAny`: contém algum dos ids
- `containsAll`: contém todos os ids
- `size`: tem um número de itens (`[size][gte]=2`)
- `isEmpty`: não tem itens (`true`/`false`)
