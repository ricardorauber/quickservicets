Run the commands with `bun run quickservice <command>` inside a project.

## `init`

Creates a project; inside the QuickService monorepo it also links the workspace packages and installs them.

```bash
quickservice init [directory] [--db postgres|mongodb|sqlite|memory]
```

## `dev`

Builds and serves the project, rebuilding and restarting when entities, endpoints, hooks or the config change.

```bash
quickservice dev
```

## `build`

Generates `.generated/`: models, routes, types, the OpenAPI document and the server entry.

```bash
quickservice build
```

## `migrate`

Applies pending migrations, or migrates up or down to the target migration.

```bash
quickservice migrate [target] [--force]
```

## `migration add`

Creates a migration from the model changes since the last one.

```bash
quickservice migration add <Name>
```

## `migration list`

Lists the migrations and whether each one is applied.

```bash
quickservice migration list
```

## `migration remove`

Removes the latest migration when it is not applied.

```bash
quickservice migration remove
```

## `migration script`

Prints, or writes to a file, the SQL of the migrations between two points.

```bash
quickservice migration script [from] [to] [--output <file>]
```

## `--version`

Prints the CLI version.

```bash
quickservice --version
```
