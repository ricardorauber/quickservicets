## Uma API completa a partir de um arquivo

```ts title="entities/User.ts"
export type User = {
  /** @unique @format email */
  email: string;
  name?: string;
  /** @default 'member' */
  role: "member" | "admin";
};
```

E ela já responde:

```bash
curl -X POST localhost:3000/users -d '{"email":"ana@x.co"}'
# {"id":"01a1…","email":"ana@x.co","name":null,"role":"member",…}
```
