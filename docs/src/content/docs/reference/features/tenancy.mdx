Multi-tenancy: every request is resolved to a tenant from a header, a subdomain, a path prefix, the credentials or a function.

## Enabling

Turn it on in `quickservicets.config.ts`:

```ts
tenancy: {}
```

It is not enabled by default: turn it on with `tenancy: {}` or `QS_TENANCY_ENABLED=true`, and off with `tenancy: false` or `QS_TENANCY_ENABLED=false`.

**Runs after:** `http`

## Tags

### `@tenancy`

`@tenancy shared` makes an entity's records shared by every tenant; on an endpoint, `@tenancy off` exempts it from tenant resolution and `@tenancy required=false` lets it run without a tenant.

**Applies to:** entities, endpoints

**Syntax:** `@tenancy <scope> [required=…]` or `@tenancy off`

**Options:** `tenancy.scope`, `tenancy.required`

```ts
/** @tenancy shared */
export type Plan = { name: string };
```

## Commands

### `tenants list`

Prints each tenant with its status, strategy, schema name or database, and plan; --pending adds its number of pending migrations.

```bash
quickservicets tenants list [--pending]
```

**Flags:**

- `--pending` (`boolean`, default `false`): Adds the number of migrations each tenant has not applied.

### `tenants create`

Adds a tenant of the database source as suspended, migrates its schema or database, then makes it active.

```bash
quickservicets tenants create <id> [--plan <plan>] [--strategy <schema|database>] [--schema <name>] [--connection <value>]
```

**Arguments:**

- `<id>` (required): The tenant's id: lowercase letters, digits and dashes.

**Flags:**

- `--plan` (`string`): The tenant's plan.
- `--strategy` (`"schema" \| "database"`): Where the tenant's data lives, over tenancy.strategy.
- `--schema` (`string`): The tenant's schema name, over the tenancy.schema template.
- `--connection` (`string`): The connection of a database-strategy tenant; it is never printed.

### `tenants suspend`

Suspends a tenant of the database source: its requests answer 403.

```bash
quickservicets tenants suspend <id>
```

**Arguments:**

- `<id>` (required): The tenant's id.

### `tenants resume`

Makes a suspended tenant of the database source active again.

```bash
quickservicets tenants resume <id>
```

**Arguments:**

- `<id>` (required): The tenant's id.

## Jobs

Jobs run while the feature is enabled; a project file `jobs/<name>.ts` replaces one.

| Job | Schedule | Description |
| --- | --- | --- |
| `tenancy/relay` | `@daily` | Moves, every day, the queue and outbox rows that database-strategy tenants staged and no relay moved yet (a crash between a commit and its relay), opening their pools as needed. |

## Feature API

Other features reach it with `ctx.feature("tenancy")` in their setup, listing `tenancy` in `requires` or `after`.

### `exempt`

```ts
exempt(pattern: string): void;
```

Exempts the paths matching `pattern` (a path, or a path ending in `/*` for it and every path below it) from tenant
resolution: their requests get no `req.tenant` and need none. Only available during setup.

### `find`

```ts
find(id: string): Promise<TenantInfo | undefined>;
```

The tenant with this id from the directory, through the worker's cache, or undefined when there is none.

### `list`

```ts
list(): AsyncIterable<TenantInfo>;
```

Every tenant of the directory, read page by page without the cache.

### `stats`

```ts
stats(): PoolStats;
```

The tenant database pools of this worker: open, the limit, openings in progress and tenants failing to open.

### `provision`

```ts
provision(info: Partial<TenantInfo> & { id: string }): Promise<TenantProvisionResult>;
```

Creates a tenant of the database source and migrates it; refuses an existing id with `Tenant <id> already exists`.

### `run`

```ts
run<T>(id: string, fn: (context: TenantRunContext) => T | Promise<T>): Promise<T>;
```

Runs `fn({ tenant, repos })` inside the database scope of the tenant `id`, like `runForTenant`; rejects for unknown
and suspended tenants.

### `migrate`

```ts
migrate(id: string): Promise<TenantProvisionResult>;
```

Applies the pending migrations to one tenant; rejects with `Unknown tenant <id>` for an unknown one.
