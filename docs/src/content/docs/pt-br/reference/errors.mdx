Toda resposta de erro tem o formato `{ "error": { "code", "message", "details"? } }`. O código depende só do status HTTP.

| Status | Código |
| --- | --- |
| 400 | `VALIDATION_ERROR` |
| 401 | `UNAUTHORIZED` |
| 403 | `FORBIDDEN` |
| 404 | `NOT_FOUND` |
| 405 | `METHOD_NOT_ALLOWED` |
| 409 | `CONFLICT` |
| 413 | `PAYLOAD_TOO_LARGE` |
| 415 | `UNSUPPORTED_MEDIA_TYPE` |
| 500 | `INTERNAL_ERROR` |

## Mensagens

| Status | Mensagem | Quando |
| --- | --- | --- |
| 400 | `Invalid JSON body` | O body não é um JSON válido. |
| 400 | `Invalid body` | A validação falhou; `details` lista cada campo, por exemplo `Is required`, `Unknown field`, `Field is read-only`, `Cannot be null`, `Must be a string`, `Must be one of: <valores>`. |
| 400 | `Referenced record not found` | Uma referência ou item de reference array aponta para um registro que não existe (em `details`). |
| 400 | `Invalid query` | Um parâmetro de query ou item de query tipada é inválido, por exemplo `Unknown parameter`, `Parameter is repeated`, `Must be an integer from 1 to 100`. |
| 400 | `Populate depth exceeds <n>` | Um caminho de populate tem mais segmentos que `populate.maxDepth`. |
| 403 | `Invalid or expired signature` | Uma URL de arquivo assinada está errada ou expirou. |
| 404 | `Route not found` | Nenhuma rota corresponde ao caminho. |
| 404 | `<Entity> not found` | Nenhum registro tem esse id. |
| 405 | `Method not allowed` | O caminho existe com outros métodos, listados no header `allow`. |
| 409 | `Value already exists` | Um campo `@unique` já tem esse valor. |
| 409 | `Cannot delete: referenced by <collection>` | Uma referência `restrict` ainda aponta para o registro. |
| 413 | `File too large` | Um upload é maior que o tamanho permitido. |
| 413 | `Total upload size too large` | Os arquivos de um campo array, somados, passam do `@maxTotalSize`. |
| 415 | `Must be multipart/form-data` | Uma entidade de arquivo foi escrita com JSON em vez de um body multipart. |
| 500 | `Internal server error` | Um erro inesperado; fora de produção, `details.stack` traz o stack trace. |
