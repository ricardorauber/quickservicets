As tags configuram entidades, campos e endpoints. Esta página lista todas as tags embutidas; ela é gerada a partir dos registros de tags do framework.

## Tags de entidade

Escritas no comentário JSDoc acima de um tipo de entidade. Qualquer outra tag numa entidade aponta um hook de `hooks/`.

### `@collection`

Nome da tabela ou coleção e das rotas (padrão: o plural do nome da entidade).

**Vale para:** Entidades

```ts
/** @collection people */
export type Person = { name: string }
```

### `@schema`

Schema do banco da entidade (padrão: a pasta dela dentro de `entities/`, ou o schema padrão).

**Vale para:** Entidades

```ts
/** @schema auth */
export type Account = { email: string }
```

### `@overrideHooks`

`inherit` (padrão) ou `replace`: se endpoints que sobrescrevem uma rota gerada mantêm os hooks da entidade.

**Vale para:** Entidades

```ts
/** @overrideHooks replace */
export type User = { email: string }
```

### `@fields`

Campos que as rotas de listagem e leitura devolvem; limite com `:list` ou `:read`.

**Vale para:** Entidades

```ts
/** @fields:list id,name */
export type User = { name: string; bio?: string }
```

### `@populate`

Caminhos de referência populados por padrão na listagem e na leitura; limite com `:list` ou `:read`.

**Vale para:** Entidades

```ts
/** @populate:read organization */
export type User = { organization: Organization }
```

### `@storage`

Storage dos objetos de uma entidade de arquivo (padrão `default`).

**Vale para:** Entidades de arquivo

```ts
/** @storage archive */
export type Document = File & { title?: string }
```

### `@maxSize`

Maior upload que uma entidade de arquivo aceita (padrão `files.maxSize`).

**Vale para:** Entidades de arquivo

```ts
/** @maxSize 5MB */
export type Avatar = Media
```

### `@accept`

Padrões MIME que uma entidade de arquivo aceita (padrão `files.accept`).

**Vale para:** Entidades de arquivo

```ts
/** @accept image/png,image/jpeg */
export type Avatar = Media
```

### `@access`

Como funcionam as URLs dos arquivos: `direct`, `proxy` ou `signed [ttlSegundos]` (padrão `files.access`).

**Vale para:** Entidades de arquivo

```ts
/** @access signed 60 */
export type Contract = File
```

### `@internal`

Não cria rotas para a entidade; ela só é usada pelo código.

**Vale para:** Entidades

```ts
/** @internal */
export type AuditLog = { action: string }
```

## Tags de campo

Escritas no comentário JSDoc acima de um campo de uma entidade.

### `@unique`

Recusa um valor que outro registro já tem, com 409 `Value already exists`.

**Vale para:** Campos de primeiro nível que não são arrays nem objetos

```ts
/** @unique */ email: string
```

### `@index`

Cria um índice no banco para o campo, deixando filtros e ordenação mais rápidos.

**Vale para:** Campos de primeiro nível que não são arrays nem objetos

```ts
/** @index */ country: string
```

### `@default`

Valor usado quando o body de criação não traz o campo; campos enum também aceitam `Enum.membro`.

**Vale para:** Qualquer campo

```ts
/** @default 'member' */ role: "member" | "admin"
```

### `@minLength`

Tamanho mínimo de um texto (`Must be at least <n> characters`); em arrays, o número mínimo de itens.

**Vale para:** Textos e arrays

```ts
/** @minLength 2 */ name: string
```

### `@maxLength`

Tamanho máximo de um texto; em arrays, o número máximo de itens.

**Vale para:** Textos e arrays

```ts
/** @maxLength 80 */ title: string
```

### `@minItems`

Número mínimo de itens (`Must have at least <n> items`).

**Vale para:** Arrays e reference arrays

```ts
/** @minItems 1 */ tags: string[]
```

### `@maxItems`

Número máximo de itens (`Must have at most <n> items`).

**Vale para:** Arrays e reference arrays

```ts
/** @maxItems 10 */ members: User[]
```

### `@min`

Menor número aceito (`Must be at least <n>`).

**Vale para:** Números

```ts
/** @min 0 */ age: number
```

### `@max`

Maior número aceito (`Must be at most <n>`).

**Vale para:** Números

```ts
/** @max 150 */ age: number
```

### `@format`

Confere se um texto é um `email` ou uma `url`.

**Vale para:** Textos

```ts
/** @format email */ email: string
```

### `@maxSize`

Maior arquivo que o campo aceita, além do limite da própria entidade de arquivo.

**Vale para:** Referências e reference arrays para entidades de arquivo

```ts
/** @maxSize 1MB */ logo?: Media
```

### `@accept`

Padrões MIME que o campo aceita, além das regras da própria entidade de arquivo.

**Vale para:** Referências e reference arrays para entidades de arquivo

```ts
/** @accept image/png,image/webp */ logo?: Media
```

### `@maxTotalSize`

Maior tamanho somado dos arquivos enviados ao campo numa requisição.

**Vale para:** Reference arrays para entidades de arquivo

```ts
/** @maxTotalSize 10MB */ gallery?: Media[]
```

### `@keepFile`

Nunca apaga o arquivo referenciado quando ele é substituído ou quando este registro é apagado.

**Vale para:** Referências e reference arrays para entidades de arquivo

```ts
/** @keepFile */ contract?: File
```

### `@onDelete`

O que acontece com este registro quando o referenciado é apagado: `restrict` (padrão), `cascade` ou `setNull`; arrays aceitam `pull` (padrão), `restrict` ou `cascade`.

**Vale para:** Referências e reference arrays

```ts
/** @onDelete cascade */ organization: Organization
```

### `@inverse`

Junta o campo com um campo da entidade referenciada numa só relação; `@inverse none` mantém os dois separados.

**Vale para:** Referências e reference arrays

```ts
/** @inverse members */ organization: Organization
```

### `@owner`

Marca o lado de uma relação 1-1 que guarda a referência.

**Vale para:** Referências simples numa relação 1-1

```ts
/** @owner */ profile: Profile
```

### `@joinTable`

Dá nome à tabela de junção (ou coleção de junção) de um reference array ou de uma relação N-N.

**Vale para:** Reference arrays

```ts
/** @joinTable team_members */ users: User[]
```

### `@onConflict`

Com `replace`, ligar um alvo 1-1 que já está ligado move a ligação em vez de falhar com 409.

**Vale para:** Referências simples numa relação 1-1

```ts
/** @onConflict replace */ badge: Badge
```

### `@hidden`

Nunca devolve o campo nas respostas; `@hidden:list` ou `@hidden:read` esconde só ali.

**Vale para:** Qualquer campo

```ts
/** @hidden */ passwordHash: string
```

## Tags de endpoint

Escritas no comentário JSDoc acima do export default de um endpoint. Qualquer outra tag aponta um hook de `hooks/`.

### `@populate`

Caminhos de referência populados na resposta de um override de rota de listagem ou leitura.

**Vale para:** Overrides de rotas geradas de listagem e leitura

```ts
/** @populate organization */
```

### `@summary`

Resumo de uma linha da operação na documentação da API.

**Vale para:** Endpoints customizados

```ts
/** @summary Organization stats */
```

### `@description`

Texto mais longo da operação na documentação da API; pode ter várias linhas.

**Vale para:** Endpoints customizados

```ts
/** @description Counts the members of an organization. */
```

### `@fields`

Campos que a resposta mantém.

**Vale para:** Endpoints customizados

```ts
/** @fields id,name */
```

### `@exclude`

Campos removidos da resposta.

**Vale para:** Endpoints customizados

```ts
/** @exclude secret */
```
